🔴 Основните места, където бъркаш
1. Value type vs Reference type — най-важното
Това е №1 зоната за работа.

При:

int a = 10;
int b = a;
b = 20;

разбра, че a остава 10.

Но при:

Person a = new Person();
Person b = a;

b.Name = "Ivan";

първоначално очакваше a да остане "Maria".

След обяснението го хвана:

a и b сочат към един и същ object.

Това трябва да стане много стабилно, защото ще се появява навсякъде в C#.

2. string и immutable
Това беше ново за теб.

Знаеш вече, че string е reference type, но:

string е immutable

Тоест не променяме съществуващия string object.

Това още не е напълно автоматично.

3. Property vs Field
Разбираш общата идея много добре:

field → държи стойността
property → контролира достъпа/логиката около стойността

Но терминологията още може да се изчисти.

Особено:

private string name;              // field

public string Name { get; set; }  // property

4. abstract vs virtual
Вече си на добра позиция, но трябва да ги различаваш автоматично:

virtual
→ имам default implementation
→ наследникът МОЖЕ да я промени

abstract
→ нямам implementation
→ concrete наследникът ТРЯБВА да даде implementation

Ти не си на ниво „не знам C# fundamentals“.
