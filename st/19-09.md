DateOfBirth = 2001-04-03
Age = 25        ← автоматично
IsDateOfBirthEstimated = false
Къде да го направим
Най-подходящото място е StudentService.UpdateAsync(), защото там вече записваме промените в базата.
Добавяме изчисляването преди SaveChangesAsync().
Например:
if (!student.IsDateOfBirthEstimated)
{
    var today = DateTime.Today;

    var age = today.Year - student.DateOfBirth.Year;

    if (student.DateOfBirth.Date > today.AddYears(-age))
    {
        age--;
    }

    existingStudent.Age = age;
}
След това:
existingStudent.DateOfBirth = student.DateOfBirth;
existingStudent.IsDateOfBirthEstimated = student.IsDateOfBirthEstimated;
Но бих направил една малка корекция в реда, за да е максимално ясно:
existingStudent.DateOfBirth = student.DateOfBirth;
existingStudent.IsDateOfBirthEstimated = student.IsDateOfBirthEstimated;

if (!existingStudent.IsDateOfBirthEstimated)
{
    var today = DateTime.Today;

    var age = today.Year - existingStudent.DateOfBirth.Year;

    if (existingStudent.DateOfBirth.Date > today.AddYears(-age))
    {
        age--;
    }

    existingStudent.Age = age;
}
Така при твоя сценарий:
Update date of birth
        ↓
Save
        ↓
IsDateOfBirthEstimated = false
        ↓
Age се изчислява от DateOfBirth
        ↓
SQL Server записва и двете
Важно: за старите записи, които още имат IsDateOfBirthEstimated = true, няма да пипаме Age. Така запазваме първоначалната тестова информация, докато потребителят не потвърди истинската дата.
Ако искаш, следващата стъпка е просто да променим целия UpdateAsync() с тази логика и да го тестваме с един от старите записи.
