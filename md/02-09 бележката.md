# **<mark>8. Age hint — без JavaScript</mark>** 

Искаме hint-ът да се показва само когато Age полето е във focus. 

<mark>В</mark> wwwroot/css/site.css <mark>добавихме:</mark> <mark>`.age-hint { display: none; }`</mark> 

```
input[name="Age"]:focus ~ .age-hint {
    display: block;
}
```

<mark>Първоначално използвахме</mark> + <mark>, но hint-ът не се показваше. Причината беше, че Razor генерира допълнителен:</mark> <mark>`<input name="__Invariant" type="hidden" value="Age">`</mark> 

<mark>между Age input-а и</mark> .age-hint <mark>.</mark> 

<mark>Затова:</mark> <mark>`+` не работеше. Сменихме го с:</mark> <mark>`~`</mark> 

което означава следващ sibling елемент, дори да има друг елемент между тях. <mark>Това вече работи. ✅</mark>
