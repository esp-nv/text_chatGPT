C# Fundamentals таблицата е по-удобна. И за типовете е добре да имаш размер + диапазон, като отбележим и разликата между битове и байтове.

Само една важна поправка: не всички C# типове имат фиксиран размер. Например string, object, class и масивите не могат да се дадат просто като „8 bytes“. За тях ще отбележим reference type / variable size.

C# Fundamentals — Data Types
Тип	Размер	Диапазон / стойности	Какво пази
sbyte	1 byte = 8 bits	-128 → 127	цяло число
byte	1 byte = 8 bits	0 → 255	цяло положително
short	2 bytes = 16 bits	-32,768 → 32,767	цяло число
ushort	2 bytes = 16 bits	0 → 65,535	цяло положително
int	4 bytes = 32 bits	-2,147,483,648 → 2,147,483,647	цяло число
uint	4 bytes = 32 bits	0 → 4,294,967,295	цяло положително
long	8 bytes = 64 bits	-9,223,372,036,854,775,808 → 9,223,372,036,854,775,807	голямо цяло
ulong	8 bytes = 64 bits	0 → 18,446,744,073,709,551,615	голямо положително
float	4 bytes = 32 bits	приблизително ±1.5 × 10⁻⁴⁵ → ±3.4 × 10³⁸	floating-point
double	8 bytes = 64 bits	приблизително ±5.0 × 10⁻³²⁴ → ±1.7 × 10³⁰⁸	floating-point
decimal	16 bytes = 128 bits	приблизително ±1.0 × 10⁻²⁸ → ±7.9 × 10²⁸	точни десетични
bool	1 byte*	true / false	логическа стойност
char	2 bytes = 16 bits	U+0000 → U+FFFF	един UTF-16 символ

* При bool спецификацията не трябва да се мисли просто като „винаги 1 byte във всяка възможна ситуация“ — размерът може да зависи от контекста/представянето.

Най-важните за запомняне
1 byte  = 8 bits

byte    → 1 byte
short   → 2 bytes
int     → 4 bytes
long    → 8 bytes

float   → 4 bytes
double  → 8 bytes
decimal → 16 bytes

char    → 2 bytes

Логика за целите числа
sbyte   → 1 byte  → със знак
byte    → 1 byte  → без знак

short   → 2 bytes → със знак
ushort  → 2 bytes → без знак

int     → 4 bytes → със знак
uint    → 4 bytes → без знак

long    → 8 bytes → със знак
ulong   → 8 bytes → без знак

Правилото за диапазона при integer типовете е свързано с броя битове:

8 bits
→ 2⁸ = 256 възможни стойности

signed:
-128 → 127

unsigned:
0 → 255

Тоест при 1 byte = 8 bits имаш 256 различни комбинации, а при sbyte половината диапазон е за отрицателни стойности.

За string, object, class, array и подобни бихме записали отделно:

Тип	Категория	Размер
string	reference type	променлив
object	reference type	зависи от обекта
class	reference type	зависи от обекта
array	reference type	зависи от броя елементи

Така шпаргалката няма да те кара да запомняш грешното правило „всеки тип има фиксирани байтове“.
